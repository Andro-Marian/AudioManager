# AudioManager
And audio mixer like the EarTrumpet

With the help of https://github.com/naudio/naudio and .NET Framework 10

Right click on the slider to increase or decrease the volume smooth.  
Use <code><b>Pin</b></code> to not hide the window.  
<code><b>Devices</b></code> shows the devices page.  
<code><b>Inactive</b></code> shows the inactive sessions.
